# สแกนเอกสาร / ສະແກນເອກະສານ / Document Scanner

เว็บแอพสแกนเอกสารที่ทำงานในเบราว์เซอร์ทั้งหมด ไม่ต้องมี server

- ถ่ายรูป/เลือกรูป หลายหน้า จัดลำดับหน้าได้
- **จัดหน้าอัตโนมัติ**: แก้ความเอียงของเอกสาร + ตัดขอบตามกระดาษ (ปรับมือต่อได้: ลากกรอบ, แถบ "ปรับความเอียง")
- ปรับภาพ: โหมดขาวดำสะอาด/เทา/สี, ความสว่าง, คอนทราสต์, **ความคมชัด**, หมุน 90°
- อ่านข้อความ (OCR) ไทย / ลาว / อังกฤษ ด้วย [Tesseract.js](https://github.com/naptha/tesseract.js)
- ค้นวันที่ เบอร์โทร จำนวนเงิน จากข้อความ (ตามรูปแบบตัวเลข)
- บันทึกเป็น PDF / .txt / .csv
- **เปลี่ยนภาษาของแอพได้**: ไทย / ລາວ / English (จำค่าที่เลือกไว้ในเบราว์เซอร์)

ภาพและข้อความประมวลผลในเครื่องผู้ใช้ ไม่ส่งไปที่ใด

## วิธีโฮสต์ด้วย GitHub Pages
1. สร้าง repository ใหม่ แล้วอัปโหลด `index.html` และ `README.md`
2. Settings → Pages → Source: เลือก branch `main` และโฟลเดอร์ `/ (root)` → Save
3. รอสักครู่ จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

ต้องเปิดผ่าน https (GitHub Pages เป็น https อยู่แล้ว) กล้องมือถือจึงจะทำงาน

## ข้อจำกัด
- จัดหน้าอัตโนมัติแก้ความเอียงได้ราว ±15° และตัดขอบเป็นสี่เหลี่ยม ไม่แก้มุมมองเฉียง (เอกสารที่ถ่ายเฉียงจนเป็นสี่เหลี่ยมคางหมู) ไม่หมุน 90° ให้เอง และอาจพลาดถ้าเอกสารสีขาววางบนโต๊ะสีขาว
- ครั้งแรกที่อ่านแต่ละภาษา ต้องโหลดข้อมูลภาษา (ราว 1–10 MB) จากอินเทอร์เน็ต
- ความแม่นยำของ OCR ภาษาลาวและตัวหนังสือเล็กต่ำกว่าไทย/อังกฤษ ต้องตรวจทานเสมอ
- คำแปลภาษาลาวในแอพเขียนโดย AI ควรให้เจ้าของภาษาช่วยตรวจ (แก้ได้ที่ตัวแปร `I18N.lo` ใน `index.html`)
- ใช้ไลบรารีจาก CDN (jsDelivr, cdnjs, Google Fonts) ต้องมีอินเทอร์เน็ต
